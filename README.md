# Junbi — privacy policy and support site

Landing page, privacy policy and support for the iPhone, iPad and Mac game *Junbi: Olympic Taekwondo* (Notemia),
in 12 languages (English also serves en-GB, Spanish also serves es-MX). Served by GitHub Pages:
https://notemia.github.io/junbi-site/

Edit the copy in `_src/langs.py`, then rebuild with `python3 _src/build.py`.
Contact address and the Unity privacy-policy link are in `_src/build.py`; put the App Store address into `STORE` once the app is live.
